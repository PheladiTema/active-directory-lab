# Active Directory Lab

## Overview

This project was completed as part of my Zaio Cybersecurity Bootcamp.

The project provided practical exposure to managing and securing a Windows Active Directory environment. It helped me understand how organisations can use Active Directory to manage users, computers, groups, permissions and access across a network.

## Objectives

- Understand the fundamentals of Active Directory
- Gain practical exposure to user and account management
- Work with groups and permissions
- Understand organisational units and directory structure
- Explore basic Windows security administration
- Understand the importance of access control in an enterprise environment

## Technologies & Tools

- Windows Server
- Active Directory Domain Services (AD DS)
- Windows Active Directory
- Group and User Management
- Access Control
- Windows Administration

## Skills Demonstrated

- Active Directory administration
- User and group management
- Access control
- Windows security fundamentals
- System administration
- Troubleshooting
- Cybersecurity fundamentals

## Key Learning Outcomes

Through this project, I developed a better understanding of how Active Directory is used to manage identities, systems and access within an organisational environment.

The practical exercises helped me understand the relationship between users, groups, computers and permissions, as well as the importance of properly managing access to organisational resources.

## Cybersecurity Relevance

Active Directory is widely used in enterprise environments, making an understanding of identity and access management an important foundation for cybersecurity roles.

This project strengthened my understanding of:

- Identity and Access Management (IAM)
- Privileged access
- User and group permissions
- Windows security
- Enterprise environments
